# ColorMusicQW
Создан полный скетч Arduino для цветомузыки с FFT-анализом аудиосигнала, разделяющего спектр на 6 частотных диапазонов (20 Гц - 8 кГц), каждый из которых управляет отдельной светодиодной лентой через PWM-выходы с использованием MOSFET транзисторов. Включает шумоподавление, плавное сглаживание яркости, оконную функцию Хэмминга и настраиваемые параме
